# 싹둑 · 포장지 재단 계산기

[![Developer](https://img.shields.io/badge/Developer-cybereun-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/cybereun)
[![Live Demo](https://img.shields.io/badge/Live_Demo-싹둑_열기-d63a30?style=for-the-badge)](https://cybereun.github.io/ssakduk/)
[![License: MIT](https://img.shields.io/badge/License-MIT-0f3b2e?style=for-the-badge)](LICENSE)

선물 상자, 원통, 병의 크기를 넣으면 필요한 포장지 크기와 재단선을 보여 주고, 종이가 감기는 모습을 3D 애니메이션으로 미리 보여 주는 웹앱입니다. 종이를 모자라게 자르는 사고를 미리 막아 줍니다.

## 실행
`run.bat`을 더블클릭하면 기본 브라우저에서 랜딩 페이지가 열리고, 큰 빨간 버튼을 누르면 앱(`app/index.html`)으로 들어갑니다. 설치할 것도, 서버도 필요 없습니다.

배포 주소: https://cybereun.github.io/ssakduk/

3D 라이브러리(Three.js r149)는 `app/vendor/`에 들어 있어 인터넷 없이도 동작합니다. 글꼴만 구글 폰트를 쓰고, 연결이 없으면 시스템 글꼴로 대신 보입니다.

## 할 수 있는 것
- **7가지 모양**: 상자 · 납작한 것(책, 액자, 카드) · 원통 · 병 · 공·인형 · 삼각기둥 · 봉투·가방. 모양마다 자주 쓰는 크기 버튼이 있어요.
- **포장 방식**(상자·납작): 기본 감싸기 · 일본식 대각선 · 보자기. 방식마다 필요한 종이(또는 천) 크기, 재단도, 접는 순서, 3D 애니메이션이 달라져요.
- **내 포장지** 입력: 롤(폭만), 낱장(가로×세로, A2·A1·전지 버튼), 제한 없음
- **결과 태그**: 필요한 포장지 크기, 롤에서 잘라야 할 길이, 종이 이용률(별점), 남는 종이
- **모자라면** 몇 cm가 모자란지 폭과 길이로 나눠 알려 주고, 더 알뜰한 방향이나 더 넓은 롤을 제안
- **한 롤에 배치**: 선물을 목록에 담으면(수량 포함) 롤 위에 조각을 테트리스처럼 맞춰 보여 주고, 필요한 롤 길이·이용률·남는 자투리를 계산해요. 가진 롤 길이를 넣으면 "충분해요 / 90cm 모자라요"로 답해요.
- **사진으로 크기 재기(대략)**: A4 용지를 선물 옆 같은 바닥에 놓고 찍은 사진에서, A4 모서리 4곳을 눌러 기준을 잡고 선물의 양 끝을 눌러 크기를 재요. 높이는 옆에서 찍은 사진으로 따로 재요. 사진은 기기 안에서만 쓰고 어디에도 올리지 않아요.
- **재단도**: 뒷면 격자 위에 재단선(빨간 점선), 접는 선(파란 점선), 면별 치수. 가위가 재단선을 따라 지나가고 잘린 종이가 떠오름
- **포장 미리보기(3D)**: 상자는 펼치기 → 양옆 감싸기 → 윗면 겹쳐 붙이기 → 끝 접기 → 리본·매듭, 원통과 병은 돌돌 말기 → 끝 오므리기 → 리본, 공·인형은 종이를 위로 모아 묶기, 삼각기둥은 세 면을 감싸고 삼각형 끝을 접기, 대각선·보자기는 마름모 종이의 모서리를 접어 올리기
  - 재생/일시정지, 처음으로, 0.5×/1×/2× 속도, 슬라이더로 앞뒤 이동, 단계 버튼
  - 드래그로 회전, 휠·핀치로 확대, 자동 카메라 켜고 끄기
  - 종이가 모자라면 실제로 이음새가 벌어지는 모습과 "😱 N cm 모자라요"가 나옴
- **꾸미기**: 포장지 무늬 6종, 리본 색 4종
- **방향 비교**(상자): 가로·세로·높이 방향(대각선·보자기는 어느 면을 위로 둘지)으로 만들 때의 종이 크기와 이용률을 나란히 보여 주고 가장 알뜰한 쪽을 추천
- 순서 안내에 접는 선 위치(cm)와 리본 필요 길이까지 계산해 줌
- **잔잔한 캐롤 BGM**: 접속하면 바로 재생하고(브라우저가 소리를 막으면 첫 클릭·터치 때 시작), 끄면 다음부터 자동으로 켜지지 않아요
- 라이트/다크 테마, 모바일 화면 대응

## 계산 기준 (근사값)
| 모양 | 둘레 방향 | 끝(축) 방향 |
|---|---|---|
| 상자 | 2×(긴 변 + 짧은 변) + 이음 겹침 | 축 길이 + 짧은 변 + 2cm |
| 원통 | π×지름 + 이음 겹침 | 높이 + 지름 + 6cm (양끝 오므려 묶는 여분) |
| 병 | π×지름 + 이음 겹침 | 높이 + 반지름 + 1cm + 9cm (바닥 접기 + 병목 위) |
| 삼각기둥 | 3×한 변 + 이음 겹침 | 길이 + 2×(0.35×한 변 + 1.5cm) |
| 봉투·가방 | 2×(폭 + 두께) + 이음 겹침 | 높이 + 2×(두께/2 + 3cm) (아래 접기 + 위 닫기) |
| 공·인형 | 정사각형 한 변 = 2×(π×반지름 + 4cm) | 위로 모아 묶는 여분 포함 |
| 일본식 대각선 | 정사각형 한 변 = (두 밑면 변의 합 + 2×높이)/√2 + 이음 겹침 | 상자를 45°로 돌려 놓고 모서리를 접어 올림 |
| 보자기 | 대각선과 같은 식 + 매듭 여분 12cm | 천(정사각형) |

이음 겹침 기본값은 3cm이고 왼쪽 "이음 겹침" 슬라이더로 2~6cm까지 바꿀 수 있어요. 실제 포장에서는 종이 두께와 접는 습관에 따라 ±1cm 정도 달라질 수 있습니다.

## 파일
- `bgm.js`: 캐롤 BGM(Web Audio 합성)과 켜기/끄기 버튼
- `index.html`: 크리스마스 랜딩 페이지(전구 줄, 눈, 선물 일러스트, 크리스마스 D-day)
- `app/index.html`, `app/css/style.css`: 앱 화면과 디자인(매트 초록 · 리본 빨강 · 크라프트, 선물 태그 결과 카드)
- `app/js/calc.js`: 계산 엔진 (모양별 필요 종이, 롤/낱장에 올려 보기, 방향 비교)
- `app/js/diagram.js`: 재단도 SVG와 가위 애니메이션
- `app/js/stage3d.js`: 3D 장면. 장면 전체가 시간 t의 함수라서 슬라이더로 어디를 끌어도 맞는 모습이 나와요
- `app/js/pack.js`: 여러 선물을 한 롤에 배치(스카이라인 방식, 회전 허용)와 그림
- `app/js/photo.js`: 사진 속 A4 기준 크기 재기(호모그래피)
- `app/js/app.js`: 입력, 결과, 탭, 재생 컨트롤, 선물 목록 연결
