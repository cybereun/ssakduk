# 싹둑 · 포장지 재단 계산기

선물 상자, 원통, 병의 크기를 넣으면 필요한 포장지 크기와 재단선을 보여 주고, 종이가 감기는 모습을 3D 애니메이션으로 미리 보여 주는 웹앱입니다. 종이를 모자라게 자르는 사고를 미리 막아 줍니다.

## 실행
`run.bat`을 더블클릭하면 기본 브라우저에서 랜딩 페이지가 열리고, 큰 빨간 버튼을 누르면 앱(`app/index.html`)으로 들어갑니다. 설치할 것도, 서버도 필요 없습니다.

배포 주소: https://cybereun.github.io/ssakduk/

3D 라이브러리(Three.js r149)는 `app/vendor/`에 들어 있어 인터넷 없이도 동작합니다. 글꼴만 구글 폰트를 쓰고, 연결이 없으면 시스템 글꼴로 대신 보입니다.

## 할 수 있는 것
- **상자 · 원통 · 병** 세 가지 모양, 자주 쓰는 크기 버튼(신발 상자, 책, 머그컵, 와인 등)
- **내 포장지** 입력: 롤(폭만), 낱장(가로×세로, A2·A1·전지 버튼), 제한 없음
- **결과 태그**: 필요한 포장지 크기, 롤에서 잘라야 할 길이, 종이 이용률(별점), 남는 종이
- **모자라면** 몇 cm가 모자란지 폭과 길이로 나눠 알려 주고, 더 알뜰한 방향이나 더 넓은 롤을 제안
- **재단도**: 뒷면 격자 위에 재단선(빨간 점선), 접는 선(파란 점선), 면별 치수. 가위가 재단선을 따라 지나가고 잘린 종이가 떠오름
- **포장 미리보기(3D)**: 상자는 펼치기 → 양옆 감싸기 → 윗면 겹쳐 붙이기 → 끝 접기(옆날개·아래·위) → 리본·매듭, 원통과 병은 돌돌 말기 → 끝 오므리기 → 리본
  - 재생/일시정지, 처음으로, 0.5×/1×/2× 속도, 슬라이더로 앞뒤 이동, 단계 버튼
  - 드래그로 회전, 휠·핀치로 확대, 자동 카메라 켜고 끄기
  - 종이가 모자라면 실제로 이음새가 벌어지는 모습과 "😱 N cm 모자라요"가 나옴
- **꾸미기**: 포장지 무늬 6종, 리본 색 4종
- **방향 비교**(상자): 가로·세로·높이 방향으로 감쌀 때의 종이 크기와 이용률을 나란히 보여 주고 가장 알뜰한 쪽을 추천
- 순서 안내에 접는 선 위치(cm)와 리본 필요 길이까지 계산해 줌
- 라이트/다크 테마, 모바일 화면 대응

## 계산 기준 (근사값)
| 모양 | 둘레 방향 | 끝(축) 방향 |
|---|---|---|
| 상자 | 2×(긴 변 + 짧은 변) + 이음 겹침 | 축 길이 + 짧은 변 + 2cm |
| 원통 | π×지름 + 이음 겹침 | 높이 + 지름 + 6cm (양끝 오므려 묶는 여분) |
| 병 | π×지름 + 이음 겹침 | 높이 + 반지름 + 1cm + 9cm (바닥 접기 + 병목 위) |

이음 겹침 기본값은 3cm이고 왼쪽 "이음 겹침" 슬라이더로 2~6cm까지 바꿀 수 있어요. 실제 포장에서는 종이 두께와 접는 습관에 따라 ±1cm 정도 달라질 수 있습니다.

## 파일
- `index.html`: 크리스마스 랜딩 페이지(전구 줄, 눈, 선물 일러스트, 크리스마스 D-day)
- `app/index.html`, `app/css/style.css`: 앱 화면과 디자인(매트 초록 · 리본 빨강 · 크라프트, 선물 태그 결과 카드)
- `app/js/calc.js`: 계산 엔진 (모양별 필요 종이, 롤/낱장에 올려 보기, 방향 비교)
- `app/js/diagram.js`: 재단도 SVG와 가위 애니메이션
- `app/js/stage3d.js`: 3D 장면. 장면 전체가 시간 t의 함수라서 슬라이더로 어디를 끌어도 맞는 모습이 나와요
- `app/js/app.js`: 입력, 결과, 탭, 재생 컨트롤 연결
